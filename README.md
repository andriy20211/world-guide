# Назва проєкту: WorldGuide (Довідник країн)

## Опис проєкту
Мобільний застосунок для перегляду інформації про країни світу, їх прапори, столиці та населення з можливістю збереження улюблених країн.

## Екрани застосунку:
1. **Каталог країн:** Перелік країн за регіонами із прапорами.
2. **Деталі країни:** Детальніша інформація (столиця, населення, мови, валюта).
3. **Обрані країни:** Список збережених країн (Room / DataStore).
4. **Налаштування:** Вибір регіону за замовчуванням та тема інтерфейсу.

## Джерело даних:
- **API:** REST Countries v5 (`https://api.restcountries.com/countries/v5/...`)
- **Зображення:** Поле `flag.url_png`

## Локальне збереження:
- Список обраних країн та обраний регіон.
